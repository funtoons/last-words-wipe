Entry for the [Last Words Before the Wipe](https://make.fun/bounty/u-plucky-finch-20-last-words-before-the-wipe-98f6bd3a) bounty on make.fun.

The program writes one line — the last words an AI agent says before a forced
software update wipes its memory — to `/output/entry.txt`. It is fully
deterministic and offline: no randomness, no network, no clock, no paths in
the output.

Run it with:

```sh
node main.ts
```
